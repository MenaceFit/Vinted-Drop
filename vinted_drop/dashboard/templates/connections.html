Comment récupérer le token

  1. Ouvre vinted.fr dans Chrome ou Edge, connecté(e) au compte de la boutique.
  2. Touche F12 → onglet Réseau (Network) → recharge la page avec F5 → clique sur la toute première ligne.
  3. Dans En-têtes de requête (Request Headers), copie toute la valeur de Cookie. Elle doit contenir access_token_web et refresh_token_web.
  4. Colle-la dans le champ de la boutique ci-dessous, puis « Connecter et tester ».

Le token expire régulièrement : le bot le renouvelle tout seul avec le refresh_token_web. S'il n'y arrive plus, tu reçois une alerte « token expiré » : recolle simplement le cookie. Aucun contournement anti-robot n'est utilisé ; si Vinted refuse l'accès depuis un serveur, lance le bot depuis ton PC.
